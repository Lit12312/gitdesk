# GitDesk · 本地 Git 桌面面板

一个只在你自己电脑上运行的 Git 图形工具：多仓库切换、改动的暂存与提交、提交历史与分支图、分支管理，以及出错时最常用的几种「救急」操作。

- 查看改动、暂存和提交等操作在本机执行。获取、拉取或推送时，Git 会连接该仓库配置的远程。
- 不依赖命令行记忆：常用操作都是按钮 + 明确的中文提示。
- 危险操作都要二次确认（部分需要手动输入「丢弃 / 清理 / 删除」才能继续）。
- 界面为深色、原生窗口（Electron），窗口内没有浏览器地址栏。

## 启动

先安装 Git for Windows，并确认在 PowerShell 中运行 `git --version` 能显示版本号。

将 Windows 便携版完整解压，双击目录内的 `GitDesk.exe`。从源码打包时，该目录位于 `dist\GitDesk-win32-x64\`。

1. 点击左上角「添加仓库」（或按 `Ctrl+O`），选择已经用 Git 管理的本地项目文件夹。
2. 在「变更」中点击文件预览差异，勾选本次要提交的文件并点「暂存」。
3. 填写提交信息，点击「提交」。提交保存在本机，可在「历史」里查看。连接远程仓库后，可在「分支」里推送。

## 功能

### 侧栏 · 多仓库
- 每个仓库卡片显示：分支名、领先/落后远程的提交数、未提交改动数量。
- 点卡片即切换仓库；悬停右上角 `⋯` 可以「在资源管理器中打开」或「从列表移除」（只是从列表移除，不会删除任何文件）。
- 「刷新」会重新读取所有仓库状态。

### 变更
- 文件按「冲突 / 已暂存 / 更改 / 未跟踪」分组，支持勾选后批量「暂存 / 取消暂存 / 丢弃」。
- 点文件名在右侧查看差异；新文件按整份文件展示，冲突文件展示工作区内容（含冲突标记）。
- 底部写提交信息，`Ctrl+Enter` 提交；勾选「修改上次提交」可 amend。
- 顶部筛选框可按路径过滤文件。

### 历史
- 提交图（SVG 分道绘制）、分支/标签 chip、作者与相对时间。
- 可以按「全部分支 / 当前分支 / 指定分支」查看，支持搜索提交信息、作者、hash。
- 点一次提交，右侧显示提交信息、改动文件列表，以及每个文件的具体差异。

### 分支
- 本地分支：切换、合并到当前分支、删除（未合并时会要求二次确认）、重命名、复制名字。
- 远程分支：一键检出为本地分支。
- 顶部有「获取远程 / 拉取 / 推送 / 发布到远程」。

### 救急
- **撤销上次提交（保留改动）**：`git reset --soft HEAD~1`。
- **stash**：保存当前改动、应用、应用并删除、删除（需输入确认）。
- **丢弃所有未暂存改动 / 清理未跟踪文件**：都是不可恢复操作，必须手动输入确认词。
- **reflog**：最近 60 条 HEAD 移动记录，可以「建分支」（最安全的找回方式）或「重置」当前分支。
- **从某次提交恢复单个文件**：输入提交号和该提交里存在的文件路径，恢复到工作区。暂存区里的内容会保留。
- **冲突处理**：一键采用「当前分支版本 / 对方版本」并标记为已解决。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+O` | 添加仓库 |
| `F5` | 刷新当前仓库 |
| `Ctrl+Enter` | 提交（提交信息框内） |

## 数据保存在哪

仓库列表保存在 `%APPDATA%\GitDesk\repos.json`（只记录路径和上次打开哪个仓库，不含任何代码或凭据）。
卸载或删除 exe 不会碰你的仓库；反过来删掉这个 json 也只是清空列表。

## 已知边界

- 只处理本地仓库和标准 git 操作；不提供账号管理、PR、代码评审等托管平台功能。
- 不使用 `sudo`/提权，不改你仓库的 git 配置（`user.name`/`user.email` 只读展示）。
- 二进制文件、超大文件（>8MB）不预览内容。
- 冲突处理只提供「整体采用某一边」，不做逐行合并。

## 开发

在项目根目录运行以下命令。

```powershell
npm ci
npm start            # 开发运行
npm test             # Git 执行层测试
npm run pack         # 打包到 dist\
```

调试参数（仅开发模式生效）：

```powershell
electron . --dev-repo="D:\path\to\repo" --log=D:\tmp\app.log
electron . --shot-all=D:\tmp\shots     # 自动截图四个标签页
```
